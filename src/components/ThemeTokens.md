# Токены темы «Цифровая география»

Общие переменные в `public/assets/styles.css`: `--bg`, `--paper`, `--panel`, `--panel-soft`, `--ink`, `--muted`, `--line`, `--accent`, `--accent-soft`, `--shadow`, `--shadow-soft`, `--hero`, `--radius`.

Для тёмного режима: `html[data-theme="dark"]` изменяет значения токенов. Новые компоненты следует делать на CSS-переменных, а не на жёстко прописанных цветах.

Компоненты: `.sidebar`, `.topbar`, `.hero`, `.tile`, `.section-callout`, `.info-dialog`, `.offline-panel`, `.primary-button`.
