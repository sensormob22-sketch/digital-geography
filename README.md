# Цифровая география — Astro + PWA (прототип v0.1)

Публичный статический сайт: меню по географии 6–11 классов, светлая/тёмная темы,
три языка RU/BE/EN, шесть плиток в 9-м классе. Работа №3 — оригинальный HTML
«Метеолаб» с 10 городами, сохранён без изменения кода и климатических данных.

## Публикация за один шаг (готовая статическая версия)

В архиве `География_PWA_готовый_сайт.zip` уже есть статические файлы.
Их можно загрузить на Cloudflare Pages через **Workers & Pages → Create → Pages → Upload assets**.
В корне загружаемой папки должен находиться `index.html` (не вложенный лишний каталог).
Для GitHub Pages: содержимое можно положить в корень репозитория и включить Pages,
либо перенести в `docs/` и выбрать этот каталог как источник публикации.

## Сборка исходников Astro (нужен интернет только для первой установки)

Требования: Node.js 22.12+ (для современных обновлений используйте актуальную Node 22 LTS).

```
npm install
npm run dev
npm run build
npm run preview
npm run test:sw     # изолированная проверка офлайн-логики (не требует браузера)
```

Результат сборки: `dist/`. На Cloudflare Pages при подключении GitHub:
**Build command** `npm run build`; **Build output directory** `dist`; **Root** `/`.
Вариант без подключения GitHub: выгрузить `dist/` как готовые статические файлы.

⚠ В этой рабочей среде npm-registry недоступен (DNS), поэтому `npm run build`
здесь не выполнялся. В изолированных тестах проверена логика Service Worker;
полноценный тест опубликованной PWA в браузере остаётся необходимым.

## PWA

- Манифест: `public/manifest.webmanifest`
- Service Worker: `public/sw.js`
- Контроллер кнопок и локализация: `public/assets/pwa.js`
- Работы: `public/works/9/3/index.html`
- Реестр материалов: `src/data/catalog.json` (снимок в `content/catalog.json` статической поставки)
- Service Worker кэширует только каркас сайта при первом онлайновом открытии.
- Работа №3 **не скачивается автоматически**: в каталоге 9 класса есть кнопка
  «Скачать работу для офлайна». Открывайте её заранее, пока есть сеть.
- Кнопка удаления офлайн-копии очищает только кэш файла работы, не результаты.
- Обновления Service Worker не перезагружают активное занятие автоматически;
  пользователь подтверждает обновление.
- Сохранённые в браузере результаты индивидуальны для каждого устройства и
  браузерного профиля. Кэши могут очищаться настройками браузера/ОС.
- PWA требует HTTPS или localhost. Открытие `index.html` через `file://` показывает
  интерфейс, но **не регистрирует Service Worker**.

## Что уже работает

- 3 пункта левого меню: «О себе», «Практические работы», «Номенклатура»;
- 6 подменю классов; 6 плиток 9-го класса;
- работа №3 открывается отдельной вкладкой, не меняя свой оригинальный HTML;
- RU/BE/EN, две темы, мобильное меню;
- PWA manifest + иконки 192/512 + корректный SW scope;
- раздельные кэши каркаса и материалов, offline fallback, загрузка по кнопке;
- статус загруженной работы и возможность удаления;
- отсутствие автоматической перезагрузки при обновлении.

## Что не реализовано в прототипе

- авторизация учащихся и учительский журнал;
- серверная проверка ответов, сбор результатов или синхронизация между устройствами;
- другие практические работы (плитки обозначены как «В разработке»);
- публикация в ваши GitHub/Cloudflare аккаунты (требует вашего решения/подключения).

## Добавить работу №4

1. Разместить новый самостоятельный HTML в `public/works/9/4/index.html`.
2. Добавить запись в `src/data/catalog.json` (grade, number, title, href, offlineAssets).
3. Обновить динамическую генерацию offline-панелей: в v0.1 менеджер офлайн-работ
   специально ограничен единственной проверенной работой №3.
4. Добавить URL в список допустимых работ Service Worker и обновить версию кэша.
5. Проверить на компьютере, смартфоне, онлайн и офлайн перед публикацией.

## Особенности безопасности

PWA не защищает эталонные ответы внутри клиентского JavaScript. Для тренировочной
работы это допустимо; для официального контроля знаний нужен сервер проверки.

## Интерактивный учебный глобус · географическая номенклатура

Глобус доступен в разделе #nomenclature основной платформы и в отдельном режиме
/globus/index.html?grade=9&lang=ru. При изменении класса от 6 до 11
переключаются группы учебных объектов и их координаты, поддерживаются поиск,
поворот сферы перетаскиванием, масштабирование, выбор объекта и отображение
его точки-ориентира.

Структура:
- public/globus/index.html — автономный интерфейс учебного глобуса (WebGL,
  2D canvas fallback), адаптивный к смартфонам.
- public/globus/objects.js — дополняемый перечень тематических групп по VI–XI классам.
- public/globus/world-110m.json — географические контуры Natural Earth (public domain)
  из world-atlas, размещены локально; внешний картографический сервер не требуется.
- public/assets/app.js — интеграция глобуса с разделом «Географическая номенклатура».
- public/sw.js — сохранение интерфейса, геометрии и номенклатуры в PWA core cache;
  учитель и ученик могут открыть ранее кэшированный глобус без подключения к сети.

Учебные источники для списка:
- VI–IX классы: постановление Министерства образования Республики Беларусь
  от 29.07.2025 № 135 (учебная программа «География»).
- X–XI классы: постановление Министерства образования Республики Беларусь
  от 14.08.2026 № 143 (базовый уровень).
- Для X–XI классов часть объектов является *иллюстративными примерами*:
  экономические рейтинги стран меняются и требуют актуализации.
- Для протяженных объектов (реки, горы, страны, моря, регионы) маркер обозначает
  точку учебного ориентира, а не точную границу.
- Это первоначальная номенклатура, а не заявление об исчерпывающем перечне
  всех географических объектов школьного курса.

Проверка PWA: npm run test:sw теперь тестирует также офлайн-открытие
globus/index.html?grade=9&lang=ru, геометрию и файл названий.


## Обновление глобуса: физический / политический режимы

- **Увеличение до 26×** вместо 1,55×; при выборе объекта анимированное приближение зависит от категории: материк, океан, горы, река, озеро, государство, город.
- **Физическая карта** включается автоматически для природных объектов. При подключении сети загружается гипсометрическая и батиметрическая окраска NOAA (общественное достояние, через Wikimedia Commons, файл `Elevation.jpg`). Источник: https://commons.wikimedia.org/wiki/File:Elevation.jpg. Этот дополнительный слой сохраняется Service Worker после первого успешного обращения. Если изображение не загрузилось, показывается упрощённая **схематическая** окраска суши и океана (это **не** измеренные высоты и глубины).
- **Политическая карта** для городов и стран раскрашивает государственные полигоны Natural Earth в разные условные цвета, показывает их контуры. Геометрия локальна и доступна офлайн.
- Названия всех объектов и групп для 6–11 классов переведены на RU/BE/EN в `public/globus/translations.js`. При переключении языка выбранный объект не исчезает, координаты и исходный учебный перечень сохраняются.
- Проверки: `npm run test:globe` и `npm run test:sw`.
- **Ограничение масштаба**: источник границ масштаба 1:110m и растровая карта низкого разрешения не позволяют рассматривать здания, улицы, точные границы малых стран или действительные отметки высот на уровне отдельных точек. Изображение с палитрой высот — учебная визуализация, а не цифровая модель рельефа или навигационная карта.


### Учебная справка по объекту и условные обозначения (рабочая ветка)

В правой панели глобуса: список номенклатуры, интерактивная **«Справка по объекту»** и раскрываемая легенда **«Условные обозначения»**. При выборе элемента справка показывает текущий язык RU/BE/EN, название, тип, учебную группу, координаты точки-ориентира, режим карты, короткое проверяемое описание (для подготовленных объектов) и оригинальные справочные сведения учебного каталога, если они есть. В ином случае даётся явно универсальное пояснение, а не придуманные цифровые характеристики. Кнопка закрытия скрывает выбор. Легенда различает условную физическую шкалу / цвета государств, границы государств, обычную и активную точку. Раскраска физического слоя не является измеряемой цифровой моделью высот. Добавлен отдельный слой **приближённых учебных контуров**; точные проверенные границы и полигоны пока требуют геодатасета.

Данные: `public/globus/facts.js`, переключение режима/сопоставление с RU/BE/EN внутри `public/globus/index.html`. Новый файл входит в PWA core cache v11. Обновления выполнены в ветке `feature/globe-reference-legend`, отдельно от опубликованного сайта (не расходует сборки Netlify до слияния).


### Контуры площадных объектов и агломераций — учебный слой (рабочая ветка, октябрь 2026)

Реализованы в `feature/globe-reference-legend`, **не опубликованы на Netlify**:
- `public/globus/areas.js`: **66** приблизительных контуров природных площадных объектов и **25** контуров крупных городских районов, включая 9 мегалополисов, 16 агломераций. Данные — самостоятельные **схематические учебные обобщения**, а не точные геометрические границы или официальная статистика. Формы основаны на географической ориентировке, не должны использоваться для измерения площадей. Для океанов и больших географических областей линии не означают договорных морских границ.
- `public/globus/area-renderer.js`: отрисовка в том же ортографическом проектировании, что и глобус; обрезка невидимых фрагментов за горизонтом; обработка антимеридиана; общий слой поверх WebGL/Canvas; контуры кликабельны; выбранный контур выделяется сильнее. Природные объекты — **бирюзовый**, мегалополисы и агломерации — **малиновый**; у выбранных дополнительно тёмный контрастный ореол.
- На панели «Условные обозначения» добавлены обозначения обоих контуров и два независимых флажка видимости. В «Справке по объекту» указан характер контура: **приближённый учебный контур** или **точка-ориентир**. При выборе объекта размер приближения вычисляется по его географическому охвату. Локализация RU/BE/EN, текущая тема и PWA сохранены.
- Два новых JS-файла включены в офлайн-кэш `geo-core-2026-10-v12`. Проверки: `npm run test:sw`, `npm run test:globe`, `npm run test:areas`.

**Важно для педагогического применения:** пересечение границ контуров и неправильность их формы возможны из-за схематичности. Более точные природные объекты потребуют лицензированного/свободного геодатасета полигонов с верифицированными границами и топологией. Контуры мегалополисов традиционно условные и могут отличаться в разных учебных источниках. Отдельные маленькие водоёмы при малом увеличении могут выглядеть как точки.

### Автоматические контуры, разделение объектов и векторная картографическая основа

Номенклатура строго делится на физические объекты (материки, части света, природные регионы, рельеф, гидросфера, ООПТ) и политические/антропогенные (города, страны с учебной статистикой, агломерации, мегалополисы, экономика и экологические проблемы). **Видны только маркеры выбранного режима карты**, а при выборе объекта подходящий режим включается автоматически. Контур отображается **только у выбранного объекта** и только на соответствующей карте, чекбоксы управления контурами отсутствуют. При закрытии карточки контур исчезает.

`public/globus/vector-map.js` использует локальную векторную геометрию Natural Earth для динамической экранной отрисовки границ государств и береговой линии от 1.8×. Цветовые полигоны политической карты остаются чёткими при увеличении без обращения к внешним серверам. **Растровая подложка физического рельефа и обобщённость данных Natural Earth масштаба 1:110m остаются ограничениями**. Подсказки, текст загрузки, aria и title органов управления переведены RU/BE/EN.

Сопоставление с geokrav.by/globus: публичная страница указывает на MapLibre GL / OpenFreeMap, OpenMapTiles и OpenStreetMap. Эта инфраструктура предполагает векторные тайлы, однако при наблюдении картографический слой там не загрузился, поэтому идентичность и визуальная детализация не подтверждены. Решено сохранить независимый офлайн-глобус, без копирования чужого кода и без внешних тайлов.

### Детализация геометрии 1:50 млн

Начиная с этой версии сборка через `npm install` автоматически копирует общедоступный геодатасет `world-atlas@2.0.2/countries-50m.json` в `public/globus/world-50m.json`, а Astro помещает его в `dist/globus`. В браузере динамический векторный слой `vector-map.js` применяет более подробные контуры Natural Earth 1:50m, а встроенный `world-110m.json` остаётся резервным. Файл 50m также сохраняется в PWA-офлайн-кэше. Внешняя сеть нужна **только при сборке**, а не на компьютере ученика. Никаких OpenFreeMap, OpenStreetMap или иных сетевых тайлов при работе глобуса нет. **Детализация рельефа по высотам остаётся ограниченной разрешением растровой подложки**, а 50m геометрия по-прежнему не предназначена для увеличения до уровня улиц.

## Новый глобус: детальный рельеф, природные воды, навигация и панели (октябрь 2026)

* Физическая основа: самодостаточная локальная NASA Blue Marble (8192×4096 пикселей, исходный файл NASA через Wikimedia Commons, public domain) с более детальными ландшафтами, естественными цветами гор, суши и моря. Карта обрабатывается на экране в 8192 или меньшем размере в зависимости от `MAX_TEXTURE_SIZE` WebGL. Это **не цифровая гипсометрическая модель для измерения точных высот**; при масштабе до городских улиц детализация всё ещё ограничена.
* Гидрография: векторные реки, озёра и водохранилища Natural Earth 1:50m, из `public/globus/hydrology-50m.json` и `hydrology-renderer.js` на **обоих** глобусах, поверх государств. Номенклатурные маркеры водных объектов также остаются доступными в политическом режиме.
* При выборе нового объекта автоматический трёхфазный перелёт: отдаление до целой Земли, поворот к объекту, затем приближение к объекту. Перелёт можно отменить вращением, колесом и ручным масштабированием.
* Название активного объекта следует за его маркером на глобусе, локализуется на RU/BE/EN.
* Фиксированная высота сцены и ResizeObserver устраняют растяжение текстуры при раскрытии списков. Боковая панель — вертикальный flex-контейнер: когда легенда закрыта, список расширяется, не меняя форму Земли.
* Общие компоненты `assets/disclosures.css` и `assets/disclosures.js` — нативный доступный HTML `details/summary.geo-disclosure`, раскрытие с переходами там, где они поддерживаются, для всего проекта.
* Кнопка полноэкранного режима охватывает глобус **вместе** с боковой панелью, поддерживает мобильные экраны и CSS-резерв на браузерах без Fullscreen API.
* Все картографические файлы скачиваются **при сборке**, располагаются внутри сайта и записываются в PWA Service Worker: постоянного обращения к внешним tile API нет. `npm install` создаёт `world-50m.json`, `hydrology-50m.json`, `relief-nasa-8192.jpg` из открытых источников. Атрибуция: NASA Earth Observatory Blue Marble via Wikimedia Commons; Natural Earth public-domain dataset (NACIS).
* Для Netlify используйте `deploy/netlify` после проверки и слияния рабочего PR; ветку изменения `feature/globe-navigation-hydrology-ui` не подключайте к автоматической публикации на основной сайт.

## Стартовая страница, 9 класс — Беларусь, единый язык (октябрь 2026)

**Старт:** сайт `/` или `/#home` открывает новую анимированную главную страницу с приветствием, вращающейся Землёй, сменяющимися сообщениями и тремя путями к номенклатуре, практикам и классам. Анимации уважают `prefers-reduced-motion`. Меню содержит «Главная», логотип ведёт на неё. Язык переключается **только на главной**, в верхней панели. Выбор RU/BE/EN сохраняется единожды в `localStorage.geo_site_lang` и распространяется на портал, отдельно открытый глобус и «Метеолаб»; внутренние языковые переключатели из глобуса и практической работы удалены. Работа продолжает сохранять текущие ответы в памяти, не сбрасывая их при изменении языка в соседней вкладке.

**Рельеф Беларуси, 9 класс:** региональная учебная высотная карта создана из **настоящих значений высот** Mapzen Terrain Tiles, открытый AWS S3 набор `elevation-tiles-prod/terrarium`, масштаба карты `z=8` (256px tiles). Декодирование в метрах: `R*256 + G + B/256 - 32768`. Интерполяция цветовой шкалы в диапазоне примерно 60–380 м: низины и речные долины — тёмно-зелёные, равнины — зелёные и жёлто-зелёные, возвышенности — жёлто-оранжевые и рыжие. Простая растровая светотеневая отмывка подчёркивает формы рельефа. Результат `globus/belarus-relief-9.png` (2048×1152), границы страны строго маскируются по открытой геометрии **Natural Earth 1:50m**. Отдельная прозрачная текстура накладывается средствами WebGL **исключительно на физический глобус 9-го класса**; за границами Беларуси и для других классов сохраняется мировая карта. Исходные высоты измерены DEM, но это обзорная учебная карта, не профессиональная топосъёмка. Исходная локальная карта создаётся при `npm install` в `scripts/prepare-belarus-relief.mjs`, во время использования платформы сеть AWS не требуется.

**Воды Беларуси:** добавлен слой из 69 географических объектов рек и 33 озёрных объектов (пересекающих регион интереса) из общедоступных геоданных **Natural Earth 1:10m**, включая европейские дополнения. Они отображаются в 9-м классе поверх карты на физическом и политическом глобусах. Это обзорная, а не исчерпывающая гидросеть. Файл `globus/belarus-hydrology-10m.json` распространяется с сайтом, включён в PWA-кэш и не требует внешних картографических серверов.

**Камера:** при выборе объектов в 9 классе трёхфазный переход отдаляет только до масштаба Европы (`zoom>=7`), затем поворачивает Землю и приближает к новому объекту. Остальные классы сохраняют глобальный zoom-out.

**Атрибуция:** Mapzen (Linux Foundation) Terrain Tiles on AWS Open Data — https://registry.opendata.aws/terrain-tiles/ и https://github.com/tilezen/joerd/blob/master/docs/attribution.md; Natural Earth public domain — https://www.naturalearthdata.com/. Региональные границы масштабно обобщены; корректность легенды и DEM проверяется автоматически при сборке. Компонент `sharp` используется только при построении регионального растрового файла.

**Выпуск:** до визуальной проверки изменения находятся только в рабочей ветке `feature/home-belarus-language` и черновом PR №3. Публикационная ветка нового Netlify: `deploy/netlify`; старый Netlify-сайт остаётся без изменений.

### Выделение рек, озёр и управление глобусом (октябрь 2026)

В самостоятельном окне глобуса удалена кнопка возврата на сайт, которая при встраивании iframe создавала бесконечные вложенные копии сайта. Переходы и навигация в практических работах сохранены.

Выбор рек, озёр, возвышенностей и низменностей использует доступные географические контуры, а не фиксированное приближение к точке. Камера стремится разместить контур примерно на **75% видимой области** с максимальным техническим увеличением 650×; недостаточно подробная геометрия и отсутствие достоверного русла ограничивают реальную детализацию. Контуры природных территорий остаются приближёнными учебными. Для рек и озёр, сопоставленных с Natural Earth, выделяется именно реальная векторная геометрия с толстой двуцветной пульсирующей линией (отдельный Canvas; частота анимации ограничена для мобильных устройств; `prefers-reduced-motion` отключает пульсацию). При отсутствии подтверждённого соответствия русла выдуманная линия не рисуется.

Кнопки `+`/`−`, колесо мыши и двухпальцевое приближение/отдаление работают при выбранном объекте и без выбора; действия вручную отменяют только активный перелёт, но не очищают выбранный объект. Нативное мобильное перетаскивание одним пальцем сохранено. Подпись и справка продолжают поддерживать RU/BE/EN с единственным переключателем на главной странице.
