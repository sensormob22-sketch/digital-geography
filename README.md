# Цифровая география — Astro + PWA (прототип v0.1)

Публичный статический сайт: меню по географии 6–11 классов, светлая/тёмная темы,
три языка RU/BE/EN, шесть плиток в 9-м классе. Работа №3 — оригинальный HTML
«Метеолаб» с 10 городами, сохранён без изменения кода и климатических данных.

## Публикация за один шаг (готовая статическая версия)

В архиве `География_PWA_готовый_сайт.zip` уже есть статические файлы.
Их можно загрузить на Cloudflare Pages через **Workers & Pages → Create → Pages → Upload assets**.
В корне загружаемой папки должен находиться `index.html` (не вложенный лишний каталог).
Для GitHub Pages: содержимое можно положить в корень репозитория и включить Pages,
либо перенести в `docs/` и выбрать этот каталог как источник публикации.

## Сборка исходников Astro (нужен интернет только для первой установки)

Требования: Node.js 22.12+ (для современных обновлений используйте актуальную Node 22 LTS).

```
npm install
npm run dev
npm run build
npm run preview
npm run test:sw     # изолированная проверка офлайн-логики (не требует браузера)
```

Результат сборки: `dist/`. На Cloudflare Pages при подключении GitHub:
**Build command** `npm run build`; **Build output directory** `dist`; **Root** `/`.
Вариант без подключения GitHub: выгрузить `dist/` как готовые статические файлы.

⚠ В этой рабочей среде npm-registry недоступен (DNS), поэтому `npm run build`
здесь не выполнялся. В изолированных тестах проверена логика Service Worker;
полноценный тест опубликованной PWA в браузере остаётся необходимым.

## PWA

- Манифест: `public/manifest.webmanifest`
- Service Worker: `public/sw.js`
- Контроллер кнопок и локализация: `public/assets/pwa.js`
- Работы: `public/works/9/3/index.html`
- Реестр материалов: `src/data/catalog.json` (снимок в `content/catalog.json` статической поставки)
- Service Worker кэширует только каркас сайта при первом онлайновом открытии.
- Работа №3 **не скачивается автоматически**: в каталоге 9 класса есть кнопка
  «Скачать работу для офлайна». Открывайте её заранее, пока есть сеть.
- Кнопка удаления офлайн-копии очищает только кэш файла работы, не результаты.
- Обновления Service Worker не перезагружают активное занятие автоматически;
  пользователь подтверждает обновление.
- Сохранённые в браузере результаты индивидуальны для каждого устройства и
  браузерного профиля. Кэши могут очищаться настройками браузера/ОС.
- PWA требует HTTPS или localhost. Открытие `index.html` через `file://` показывает
  интерфейс, но **не регистрирует Service Worker**.

## Что уже работает

- 3 пункта левого меню: «О себе», «Практические работы», «Номенклатура»;
- 6 подменю классов; 6 плиток 9-го класса;
- работа №3 открывается отдельной вкладкой, не меняя свой оригинальный HTML;
- RU/BE/EN, две темы, мобильное меню;
- PWA manifest + иконки 192/512 + корректный SW scope;
- раздельные кэши каркаса и материалов, offline fallback, загрузка по кнопке;
- статус загруженной работы и возможность удаления;
- отсутствие автоматической перезагрузки при обновлении.

## Что не реализовано в прототипе

- авторизация учащихся и учительский журнал;
- серверная проверка ответов, сбор результатов или синхронизация между устройствами;
- другие практические работы (плитки обозначены как «В разработке»);
- публикация в ваши GitHub/Cloudflare аккаунты (требует вашего решения/подключения).

## Добавить работу №4

1. Разместить новый самостоятельный HTML в `public/works/9/4/index.html`.
2. Добавить запись в `src/data/catalog.json` (grade, number, title, href, offlineAssets).
3. Обновить динамическую генерацию offline-панелей: в v0.1 менеджер офлайн-работ
   специально ограничен единственной проверенной работой №3.
4. Добавить URL в список допустимых работ Service Worker и обновить версию кэша.
5. Проверить на компьютере, смартфоне, онлайн и офлайн перед публикацией.

## Особенности безопасности

PWA не защищает эталонные ответы внутри клиентского JavaScript. Для тренировочной
работы это допустимо; для официального контроля знаний нужен сервер проверки.

## Структура

```
src/pages/index.astro       — главная страница
src/layouts/MainLayout.astro — общая HTML-оболочка
src/components/SiteShell.astro — компоновка интерфейса из компонентов
src/components/SideNav.astro — боковое меню
src/components/TopNav.astro — верхняя панель
src/components/PageFooter.astro — нижняя панель
src/components/WorkCard.astro — заготовка повторного Astro-компонента
src/data/catalog.json      — данные каталога
public/assets/            — CSS, JS, иконки
public/works/9/3/          — неизменённый эталон Метеолаб
public/manifest.webmanifest — установка PWA
public/sw.js               — офлайн-кэширование и обновления
public/_headers            — заголовки для Cloudflare Pages
```
